**Дата:** 8 сентября 2026
**Метод:** rendered HTML всех страниц, JSON-LD, живые выдачи Яндекса с регионами lr=2 и lr=213, внешние профили компании.

## 1. Итог одной строкой

По сигналам, которые Яндекс использует для коммерческого локального ранжирования, **savagemovie.ru выглядит как сайт без организации за ним.** На сайте нет телефона, нет адреса, нет реквизитов, нет отзывов, а Organization-разметка описана типом, которого не существует в словаре schema.org, и ссылается на личные соцсети вместо брендовых.

Одновременно в органике Яндекса по «видеопродакшн спб», «заказать рекламный ролик спб» и «видеопродакшн москва» **у каждого конкурента** в сниппете стоят рейтинг, число отзывов и телефон.

### 2.3 Organization-разметка

`app/layout.tsx`, отдаётся на каждой странице:

```json
{
  "@type": "VideoProductionCompany",              // ← типа не существует
  "name": "Savage Movie",
  "address": { "@type": "PostalAddress",
               "addressLocality": "Санкт-Петербург",
               "addressCountry": "RU" },          // ← нет улицы и индекса
  "areaServed": ["Санкт-Петербург", "Москва", "Россия"],
  "sameAs": [ "https://vk.ru/mari_seven",
              "https://t.me/mariseven",
              "https://www.instagram.com/mari.seven/" ]   // ← личные, не бренд
}
```

Проверка по официальному словарю `schemaorg-current-https.jsonld` (1 551 177 байт, загружен 08.09.2026):

```
schema:VideoProductionCompany  -> NOT IN VOCABULARY
schema:ProfessionalService     -> PRESENT
schema:LocalBusiness           -> PRESENT
```

`VideoProductionCompany` — категория карточки Google Business Profile, а не тип schema.org.

**Отсутствуют:** `telephone`, `email`, `geo`, `openingHoursSpecification`, `priceRange`, `foundingDate`, `aggregateRating`, `image`, `vatID` / `taxID`.

**`sameAs` указывает не на ту сущность.** У Savage Movie есть собственные брендовые профили: Instagram `@savage.movie` и YouTube `@savage-movie` (обнаружены в выдаче Google по брендовому запросу). Разметка вместо них связывает домен с личными аккаунтами `mari_seven`.

### 2.4 Рекомендуемая структура (черновик — код не менялся)

```json
{
  "@context": "https://schema.org",
  "@type": "ProfessionalService",
  "@id": "https://savagemovie.ru/#organization",
  "name": "Savage Movie",
  "alternateName": "SAVAGE MOVIE",
  "url": "https://savagemovie.ru",
  "logo": "https://savagemovie.ru/sm-logo.svg",
  "image": "https://savagemovie.ru/opengraph-image",
  "description": "Продакшн-студия полного цикла в Санкт-Петербурге. Рекламные ролики, музыкальные клипы, имиджевое видео, AI-генерация.",
  "foundingDate": "2021",
  "telephone": "+7 XXX XXX-XX-XX",
  "email": "hello@savagemovie.ru",
  "priceRange": "₽₽₽",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "<фактический адрес>",
    "addressLocality": "Санкт-Петербург",
    "postalCode": "<индекс>",
    "addressCountry": "RU"
  },
  "geo": { "@type": "GeoCoordinates", "latitude": "<lat>", "longitude": "<lon>" },
  "areaServed": [
    { "@type": "City", "name": "Санкт-Петербург" },
    { "@type": "City", "name": "Москва" },
    { "@type": "Country", "name": "Россия" }
  ],
  "knowsAbout": ["Видеопродакшн", "Рекламные ролики", "Музыкальные клипы", "AI-генерация видео"],
  "sameAs": [
    "https://www.instagram.com/savage.movie/",
    "https://www.youtube.com/@savage-movie",
    "<брендовый VK>",
    "<брендовый Telegram>",
    "https://uslugi.yandex.ru/profile/SavageMovie-2736446",
    "<карточка Яндекс Бизнеса>"
  ]
}
```

**`ProfessionalService`, а не `LocalBusiness`** — потому что это подтип `LocalBusiness`, он валиден, и он точнее описывает студию, работающую по проектам, чем обобщённый `LocalBusiness`.

Дальше в графе: `Service.provider` и `WebSite.publisher` уже ссылаются на `@id` — после смены типа они начнут указывать на распознаваемую сущность.

> **Не размечайте `aggregateRating` до появления настоящих отзывов на сайте.** Разметка рейтинга без отображаемых отзывов — нарушение правил структурированных данных Google и повод для ручных санкций.

## 5. План приведения цитирований в порядок

**Шаг 0 — зафиксировать канонический NAP.** До любых правок определить единственно верные: юридическое наименование, телефон, e-mail (`hello@savagemovie.ru`), адрес, часы, год основания, ИНН/ОГРН. Дальше все площадки приводятся строго к этой записи, символ в символ.

**Шаг 1 — сайт.**
1. Телефон в футер, `/contact`, `/booking`, `/reklamny-rolik` — ссылкой `tel:`.
2. Полный NAP + реквизиты в футер.
3. Заменить `VideoProductionCompany` на `ProfessionalService`, добавить `telephone`, `geo`, `openingHoursSpecification`, `priceRange`, `foundingDate`.
4. Исправить `sameAs`: брендовые Instagram и YouTube вместо личных.

**Шаг 2 — Яндекс Бизнес.** Проверить, существует ли карточка. Если нет — создать и верифицировать. Категория «Видеостудия» / «Продакшн-студия» (та же, что у PiterPro_digital, EA Films, VILKA в локальных блоках). Заполнить: адрес, телефон, часы, сайт, 20+ фото, услуги с ценами. Привязать домен в Яндекс Вебмастере.

**Шаг 3 — Яндекс Услуги.** Заменить ссылку с YouTube на savagemovie.ru. Привести цены в соответствие с сайтом. Запустить сбор отзывов.

**Шаг 4 — каталоги.** marketing-tech.ru: телефон, реквизиты, клиенты, кейсы — поднять Trust Index с 2,5. alladvertising.ru: исправить мёртвую почту `info@savage-movie.com` на `hello@savagemovie.ru`, сверить телефон. Обе площадки стоят в TOP-10 по головным запросам обоих городов.

**Шаг 5 — 2GIS.** Проверить и создать карточку.

**Шаг 6 — региональность.** В Яндекс Вебмастере убедиться, что присвоен регион Санкт-Петербург. Это, вероятно, самый весомый единичный параметр для петербургской выдачи.

## 6. Москва без офиса

**Физического офиса в Москве нет. Выдумывать адрес недопустимо** — в Яндекс Бизнесе это ведёт к отклонению карточки, а в перспективе к потере доверия к организации целиком.

### Что ограничивает, а что нет

| Система | Влияние отсутствия московского офиса |
|---|---|
| **Google, органика** | **Незначительное.** По «видеопродакшн москва» 4 из 10 органических результатов — обычные главные страницы студий. Google не требует адреса для органики |
| **Google, локальный блок** | **Полная блокировка.** VILKA, MOSKVA PRODUCTION, ВидеоЗаяц показаны с конкретными московскими адресами. Без адреса в блок не попасть |
| **Яндекс, органика** | **Умеренное.** Ранжирование в московской выдаче возможно, но карточка Яндекс Бизнеса с петербургским адресом даёт петербургскую привязку. Московские позиции придётся брать релевантностью контента и ссылками, а не гео-сигналом |
| **Яндекс, Карты и локальные блоки** | **Полная блокировка** без московского адреса |
| **Яндекс Директ** | Не ограничено — гео-таргетинг задаётся настройками кампании |

### Честная service-area стратегия

1. **Блок «Как мы работаем в Москве»** на `/reklamny-rolik`: съёмочные группы, логистика оборудования, кастинг, павильоны и локации, московские подрядчики, сроки выезда. Никакого адреса.
2. **Поле «Город съёмки» в кейсах.** На `/reklamny-rolik` уже есть анкор «Съёмка в Москве» → `/projects/mavin` — фактическая база существует, её нужно расширить и разметить.
3. **Москва в теле главной.** Сейчас title обещает «в СПб и Москве», а слово «Москва» в тексте главной отсутствует.
4. **`areaServed`** — уже перечисляет Москву корректно.
5. **Отзывы московских клиентов** с указанием города.
6. **Что делать нельзя:** московский адрес в Яндекс Бизнесе по адресу коворкинга или партнёра; отдельная страница `/moskva/...`, отличающаяся подстановкой топонима.

**Реалистичная цель:** TOP-3 в Google Москва достижим на органике. TOP-3 в Яндекс Москва — существенно тяжелее без московской карточки. Локальные блоки обеих систем без адреса недоступны в принципе.
