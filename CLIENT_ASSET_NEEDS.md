# Ассеты для страницы /clients

Страница работает и выглядит законченной без единого пункта из этого файла —
это список того, что стоит донести позже, а не список дыр.

Проверено на данных прода (`https://savagemovie.ru/api/projects`) 7 сентября 2026:
16 брендов, 17 опубликованных проектов.

---

## 1. Логотипы клиентов

**Сейчас:** ни одного логотипа клиента в репозитории нет
(`public/` содержит только `sm-logo.svg` — логотип самой студии),
таблица `clients` в CMS пустая.

**Как страница себя ведёт:** каждый бренд набран вордмарком
(Montserrat Black Italic, тот же шрифт, что и заголовки сайта). Это осознанный
дефолт «живых титров», а не заглушка: ролл читается как список в титрах фильма.

**Что произойдёт, если логотип добавить:** в `/admin/clients` заводится запись с
`name`, совпадающим с полем «Клиент» проекта (регистр и лишние пробелы неважны),
и `logo_url`. Логотип автоматически заменит вордмарк в строке ролла, будет
приведён к белому (`brightness-0 invert`) и получит состояние по ховеру. Имя
бренда останется доступным для скринридеров.

**Требования к файлу:**

- SVG (предпочтительно) или PNG с прозрачным фоном;
- одноцветный или пригодный к приведению в белый: логотип с фотографией или
  градиентом внутри превратится в белое пятно;
- горизонтальная компоновка, высота знака не меньше 64 px в исходнике;
- официальный файл от бренда. Перерисовывать чужой знак нельзя.

**Бренды без логотипа (все 16):**
MAVIN, WELLERY, Sensual, Best Western, NAUMI, Unna, Biotherm, Dralo, Vernel,
CHERRY, SOLDATOV (T9), Совкомбанк, Diesel, Yadah, ZARINA, Охта Парк.

Приоритет — те, что вынесены в блок «Что стояло за кадром»:
**WELLERY, ZARINA, Sensual, MAVIN**.

## 2. Исходные кадры проектов: вес

Кадр для строки ролла берётся из галереи проекта (`projects.images[0]`).
Тринадцать из шестнадцати лежат в CMS как PNG весом от 1.9 до 7.5 МБ:

| Бренд | Проект | Исходник |
| --- | --- | --- |
| Best Western | best-western | 7.5 МБ PNG |
| Biotherm | biotherm | 7.1 МБ PNG |
| Unna | unna | 6.2 МБ PNG |
| Sensual | sensual-car-service | 5.7 МБ PNG |
| Dralo | dralo | 4.8 МБ PNG |
| ZARINA | zarina | 4.2 МБ PNG |
| MAVIN / NAUMI | mavin, naumi | по 3.0 МБ PNG |
| SOLDATOV (T9) | t9-soldatov | 2.6 МБ PNG |
| CHERRY / Diesel / Yadah | cherry, diesel, yadah | ~2.1 МБ PNG |
| Vernel | vernel | 1.9 МБ PNG |

Посетитель этого веса не увидит: `next/image` отдаёт WebP/AVIF нужной ширины,
а в ролле кадр запрошен с `quality={50}` и лежит под затемнением. Но первая
оптимизация каждой такой картинки нагружает сервер, и это чувствуется после
каждого деплоя, пока кеш пустой.

**Что стоит сделать:** перезалить эти кадры в CMS как WebP по длинной стороне
2000 px (три проекта — WELLERY, Совкомбанк, Охта Парк — уже так и лежат,
27–126 КБ). Кода это не касается: пути в базе те же.

## 3. Чего специально не делали

- **Не рисовали логотипы брендов.** Самодельный знак чужой компании выглядит как
  подделка и юридически небезопасен.
- **Не качали логотипы из открытых источников.** Случайный PNG с прозрачностью
  в 200 px хуже вордмарка.
- **Не ставили видео-превью в ролл.** Шестнадцать одновременных превью — это
  мегабайты трафика и просадка FPS ради эффекта, который стилл передаёт не хуже.
  Отдельного видеоассета для /clients не нужно.
- **Не придумывали цифры.** На странице нет охватов, продаж, ROI, наград и
  отзывов: в CMS этих данных нет. Единственные числа — количество брендов и
  проектов, они считаются из базы.
