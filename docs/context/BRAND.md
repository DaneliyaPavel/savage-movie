# BRAND

**Источник бренда — production savagemovie.ru и current main** ([D-01](DECISIONS.md)). Brand OS v2, Brandbook v2 и Design Tokens v2 не утверждены и не используются. Ничего здесь не выведено из них.

Разметка: **A** — устойчивый принцип · **B** — текущая реализация (можно менять) · **C** — UNVERIFIED (нужна визуальная проверка в браузере, в аудите её не было).
Источник каждого принципа: `owner` — заявлено владельцем в project instructions; `code` — виден в main; `live-text` — виден в тексте live.

## Позиционирование
Savage Movie — production-студия с авторской режиссёрской позицией: рекламные ролики, имиджевое видео, fashion/beauty, digital-контент, корпоративное видео, клипы, AI/hybrid production. База — Санкт-Петербург, съёмки в Москве и по России. Не generic-агентство, не SaaS, не личное портфолио одного видеографа. Savage Academy — связанный, но отдельный продукт (см. O-04). *(owner; live-text `/`, `/services`)*

## A. Brand principles
1. **Кадр важнее декора.** Работы — главный носитель бренда: полноэкранное шоуриль, стены кейсов, «титры» вместо логотипов. *(owner, code)*
2. **Контролируемая дерзость.** Уверенный тон и графика с намеренной неровностью (рукописные акценты, зачёркивания, «правки»), но без потери ясности: бюджет, процесс и CTA всегда читаются. *(owner, code)*
3. **Чёрный и белый доминируют, красный — сигнал.** Красный только как метка/акцент, не заливка интерфейса. *(owner, code)*
4. **Резкая иерархия: очень крупное ↔ очень мелкое.** Дисплейные заголовки против технических микро-подписей. *(owner, code `/services`, `/clients`)*
5. **Асимметрия и один доминирующий элемент на экран.** *(owner)* Реализация на новых страницах — C.
6. **Движение как монтаж.** Смена сцен, врезки, единая кривая/длительности, а не декоративная анимация; контент не ждёт анимации. *(owner, code `/services`, preloader-ident 560 мс)*
7. **Бизнес-ясность.** Красивое не заслоняет понятное: специализация, кейс, цена-ориентир, процесс, CTA. *(owner, code `/reklamny-rolik`)*

## Tone of voice (owner)
Русский основной. Короткие, конкретные, уверенные, визуальные фразы: факт → позиция → деталь. Не использовать: «уникальный подход», «инновационные решения», «команда профессионалов», «воплощаем идеи в жизнь», «wow-эффект», «премиальное качество». Не англицизм, если есть русское слово. Не обещать то, что не обеспечено процессом (срок ответа — D-04); не выдумывать клиентов, награды, отзывы, результаты.
Хорошие образцы в main: FAQ `/reklamny-rolik`, тексты `/services` после 1857e3b. Слабые: `/about` («Мы создаём визуальные истории», «Готовы творить?»), англицизмы в UI-копи («Commercial reel», «production management», «sound design»).

## Органично для Savage Movie
Тёмный экран с работой на весь кадр; крупный плотный гротеск (кириллица) против мелкой моно-подобной техники; список клиентов как титры; сцены-монтаж; зерно; рукописный красный акцент; честные цифры; фото/видео из реальных проектов.

## Чужеродно (owner + main)
SaaS-интерфейс, стены скруглённых карточек, glassmorphism, cyberpunk-неон, чёрно-золотой «люкс», стоковые агентские клише, «AI-эстетика» ради AI, центрированные шаблонные секции, pop-up/таймеры/fake urgency, тяжёлые декоративные эффекты, задерживающие контент.

## B. Current implementation (можно менять)
- Тёмная тема, фон ≈ чёрный, акцент `#ff2936`, зерно, рукописный шрифт SA No Rules, дисплей Montserrat Black / Black Italic, Epilogue Black, текст Inter ExtraLight. *(code: `app/globals.css`, `app/layout.tsx`)*
- Preloader-ident красного цвета с «камерными» спецификациями; технические подписи 35MM/T2.0/23.976 FPS на `/services`.
- Меню — полноэкранное «жалюзи» (`jalousie-menu`), плёночный ролл на главной.
Это описание того, что есть, а не запрет менять шрифты, оттенки или motion.

## C. UNVERIFIED (нужен браузер)
Реальная визуальная иерархия и асимметрия страниц; читаемость и переносы длинных русских строк; mobile/tablet; поведение при `prefers-reduced-motion` (в коде поддержка есть); контраст мелких подписей; ощущение «монтажа» в движении; сочетание двух визуальных языков (см. DESIGN_SYSTEM.md).
