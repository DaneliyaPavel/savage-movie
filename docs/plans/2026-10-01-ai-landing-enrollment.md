# AI-лендинг: запись на следующий поток — план реализации

> **Для исполнителя:** выполнять по задачам, после каждой — проверка из блока «Проверка».

**Цель:** на `ai.savagemovie.ru` добавить крупную запись на следующий поток в шапке и модальную форму предзаписи, заявки из которой приходят на hello@savagemovie.ru.

**Архитектура:** страница остаётся статическим `index.html` (inline CSS/JS, как сейчас). Форма шлёт JSON на тот же домен, на `POST /api/lead`; nginx vhost `ai.` проксирует запрос на уже работающий `https://savagemovie.ru/api/contact` (SMTP Яндекса → hello@). Код основного сайта не меняется, CORS не нужен. Лимит частоты запросов стоит на nginx.

**Стек:** HTML/CSS/vanilla JS, нативный `<dialog>`, nginx.

**Принятые решения (согласованы с владельцем):**
- Предзапись без дат и цены: условия объявим при открытии набора.
- Обещание после отправки: «Вы в списке. Когда откроем набор, Мария лично напишет вам».
- Доступ к серверу — отдельный ключ `~/.ssh/savage_ai_ed25519`, пароль вводит владелец.
- Выкатка: сначала скрытое превью `/next.html` (noindex), тестовая заявка, потом замена `index.html` с бэкапом.

## Задачи

### Task 1. Перенос страницы в репозиторий
**Файлы:** создать `sites/ai/**` (index.html, assets/, favicon*, og-closed.jpg).
**Проверка:** `find sites/ai -type f | wc -l` → 27 файлов; все `src`/`href` из `index.html` существуют на диске.

### Task 2. Шапка: блок «Запись на следующий поток»
**Файл:** `sites/ai/index.html`.
- Заменить `.status` в hero на крупный блок: пульсирующая точка, заголовок Unbounded 200, одна строка пояснения, кнопка `.btn`.
- Кнопка «Записаться» в `.topbar`.
- Полоса `.dl`, липкая плашка `.sticky`, финальный экран `.final`, карточки тарифов: «Набор закрыт» → «Предзапись» + кнопка.
- `<title>`, description, OG/Twitter: убрать «Набор в текущую группу закрыт».
**Проверка:** на 375×812 кнопка записи видна без прокрутки; `grep -c "Набор закрыт"` → 0.

### Task 3. Модальное окно и форма
**Файл:** `sites/ai/index.html`.
- `<dialog id="enroll">`, две колонки на ≥860px, шторка на мобильных.
- Поля: имя; способ связи (Telegram / Телефон / Email → одно поле); тариф; опыт (необязательно).
- Галочки: согласие на ПДн (обязательна, ссылки на `/consent`, `/privacy`), согласие на анонсы (необязательна). Обе сняты по умолчанию.
- Honeypot-поле `website`, минимальное время заполнения 3 с.
- Экраны: форма → отправка → «Вы в списке» / ошибка с запасным контактом.
- `prefers-reduced-motion`, фокус-ловушка (нативная), возврат фокуса, блокировка прокрутки.
**Проверка:** см. Task 6.

### Task 4. Контракт с `/api/contact`
Тело запроса: `name`, `phone` | `telegram` | `email`, `projectType: "course"`, `message` (источник, тариф, опыт, обе галочки с датой и версией текста).
Ответ `{success:true}` → экран «Вы в списке». Любой другой → ошибка, данные формы сохраняются.
**Проверка:** юнит-проверка функций нормализации контакта в браузере (см. Task 6).

### Task 5. nginx и деплой
**Файлы:** `infra/nginx/ai-lead-proxy.conf.example`, `scripts/deploy-ai.sh`, `sites/ai/README.md`.
- `location = /api/lead` → `proxy_pass https://savagemovie.ru/api/contact`, `limit_req 5r/m burst=5`, тело ≤ 8 КБ, только POST.
- Скрипт: бэкап текущего каталога, `rsync`, `nginx -t && nginx -s reload`, откат одной командой.
- Отдельный фикс: настоящие `robots.txt` и `sitemap.xml` вместо SPA-fallback.
**Проверка:** `nginx -t`, `curl -X POST` на превью → `{"success":true}`, письмо дошло.

### Task 6. Проверка
- Playwright/браузер: 1440×900 и 375×812, скриншоты шапки, окна, успеха, ошибки.
- Клавиатура: Tab-цикл внутри окна, Esc закрывает, фокус возвращается на кнопку.
- Валидация: пустая форма, неверный телефон/ник/email, без галочки ПДн, honeypot.
- Консоль без ошибок; сеть: один POST, `Content-Type: application/json`.

### Task 7. Ветка и PR
Ветка `feat/ai-landing-enrollment` от `origin/main`. Только пути: `sites/ai/`, `infra/nginx/ai-lead-proxy.conf.example`, `scripts/deploy-ai.sh`, `docs/plans/`, `.dockerignore`. PR без мерджа.

## Риски
- Основной сайт не имеет rate-limit: защита только на nginx `ai.`.
- Согласие `/consent` говорит про «сайт savagemovie.ru», поддомен `ai.` не назван: показать юристу.
- Если SMTP основного сайта недоступен, заявка пропадёт: ловим ошибку и показываем запасной контакт.
