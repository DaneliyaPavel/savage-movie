## 2. Первое действие: снять baseline

Пока это не сделано, любые ссылочные решения принимаются вслепую.

**Google Search Console → Links**
1. Top linking sites → экспорт CSV.
2. Top linked pages → **сверить: получает ли главная непропорционально много ссылок относительно остального сайта.** Это подтвердит или опровергнет тезис о том, что главная копит вес и никуда его не передаёт (P0-2 основного аудита).
3. Top linking text → распределение анкоров.
4. Internal links → **ожидаемое подтверждение: `/reklamny-rolik` имеет около 2 внутренних ссылок.**

**Яндекс Вебмастер → Ссылки → Внешние ссылки**
5. Экспорт полного списка + текущее значение ИКС.

**Бесплатная разведка конкурентов**
6. Moz Link Explorer, бесплатный тариф — 10 запросов в месяц. Приоритет: `kurban.studio`, `brandvideo.ru`, `madmen-production.ru`, `mosvideo.org`, `avastudio.ru`.
7. Bing Webmaster Tools после верификации домена — даёт бесплатный отчёт по входящим ссылкам.

## 4. Ассеты, которые способны привлекать ссылки

Отобраны по критерию «Savage может сделать это лучше конкурентов», а не «так принято».

| Ассет | Почему сработает | Кто сошлётся |
|---|---|---|
| **Открытая структура сметы рекламного ролика** | Ни один из проверенных лидеров не раскрывает состав сметы. `/blog/skolko-stoit-reklamnyj-rolik` уже существует и **уже в индексе Google**. «Сколько стоит» встречается в People Also Ask всех четырёх коммерческих выдач | маркетологи, агентства, vc.ru |
| **Разбор гибридного пайплайна live-action + AI** | Реальная дифференциация Savage. Кейс Biotherm «Молекула воды» | профильные медиа, AI-сообщества |
| **Глубокие кейсы с механикой и результатом** | Ни у одного проверенного конкурента нет кейсов с результатами | сайты клиентов, отраслевые подборки |
| **Гайд по локациям и логистике съёмок в Петербурге** | Прямое подтверждение петербургской экспертизы | городские и туристические ресурсы, продакшены |
| **Бесплатный шаблон брифа на видеопродакшн** | Практический инструмент; на `/reklamny-rolik` уже есть «Можно ли прислать готовый бриф?» | маркетинговые блоги, telegram-каналы |

**Чего делать не надо:** гостевые посты ради ссылки, инфографика без данных, «100 фактов о видеопродакшене», любые биржи.
