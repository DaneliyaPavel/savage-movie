# ai.savagemovie.ru: лендинг обучения AI-контенту

Статический сайт одной страницей: `index.html` (стили и скрипты внутри), картинки и видео в `assets/`,
шрифты в `assets/fonts/` (свои, без Google Fonts: адрес посетителя не уходит третьим лицам),
иконки и OG-картинки в корне, PDF-гайд в `guide/`. Внешних запросов у страницы нет, поэтому nginx отдаёт её
с жёсткой политикой CSP (`default-src 'self'`). Если добавите внешний скрипт, шрифт или картинку, разрешите домен
в CSP в `infra/nginx/conf.d/ai.savagemovie.ru.conf`. Эта папка и есть боевая:
на сервере она лежит в `/var/www/certbot/ai-landing`.

## Запись в текущую группу

Кнопки с атрибутом `data-enroll="..."` (шапка, верхняя полоса, полоса под шапкой, карточки тарифов,
финальный экран, липкая плашка) открывают окно `<dialog id="enroll">` с формой записи.
Атрибут `data-tier="basic|advanced"` сразу выбирает тариф в форме. Окно открывается и по ссылке `/#enroll`,
её можно ставить в рекламу и в Instagram.

Что происходит при отправке:

```
форма → POST /api/lead (тот же домен) → nginx ai.savagemovie.ru
      → http://frontend:3000/api/contact (Next.js основного сайта)
      → SMTP Яндекса → hello@savagemovie.ru
```

Форма шлёт обычные поля `/api/contact` плюс `source: 'ai-course'` и блок `lead` (тариф, канал, согласия, кнопка,
метки `utm_*`). Для таких заявок письмо собирает `lib/leads/ai-course.ts`: тема `ЗАПИСЬ НА КУРС - <имя>`,
карточка с кнопками «Открыть в Telegram» / «Позвонить» / «Написать на почту», таблица полей, номер заявки
(`AI-ггммдд-ччмм-XXXX`), время согласия по Москве с редакцией текста и блок «Для CRM» для копирования; к HTML
приложена текстовая версия. Без согласия на обработку данных сервер заявку не принимает (400). Старые формы сайта
работают как раньше.

Если отправка не удалась, страница показывает только `hello@savagemovie.ru`.

Защита от спама: скрытое поле «Сайт» (ловушка для ботов), минимальное время заполнения и лимит на nginx
(`limit_req`, 10 запросов в минуту с IP, ответ 429).

## Где править

| Что | Где |
| --- | --- |
| Тексты и адреса для запасных контактов | `CONFIG` в начале второго `<script>` в конце `index.html` |
| Подписи тарифов в письме | `TIERS` там же |
| Заголовок и подзаголовок блока в шапке | `.enroll` в начале `<body>` |
| Тексты окна и успеха | `<dialog id="enroll">` |
| Стили блока и окна | блок «ЗАПИСЬ НА СЛЕДУЮЩИЙ ПОТОК» в конце `<style>` |
| Описание и OG для соцсетей | `<head>`; картинка `og-next.jpg` (1200×630) |

При следующем изменении набора согласуйте с владельцем даты и цены и обновите блок в шапке, полосу `.dl`, карточки тарифов и тексты окна. Не выкладывайте сохранённый HTML поверх более новой боевой страницы без сравнения.

## Локальный запуск

```bash
node scripts/ai-dev-server.mjs        # http://localhost:4310, заявки уходят в заглушку, а не на почту
```

Режимы заглушки: `/__mode?m=ok|fail|limit|slow|bad`, последняя заявка: `/__last`.

## Выкладка

```bash
scripts/deploy-ai.sh preview     # положить как /next.html (noindex), боевую страницу не трогать
scripts/deploy-ai.sh live        # заменить index.html (перед этим бэкап в /root/backups/ai-…)
scripts/deploy-ai.sh rollback    # вернуть index.html из последнего бэкапа
scripts/deploy-ai.sh nginx       # обновить vhost и перезагрузить nginx
```

Нужен SSH-доступ к боевому серверу по ключу, адрес и пути настраиваются переменными окружения (см. шапку скрипта).

## Конфиг nginx

`infra/nginx/conf.d/ai.savagemovie.ru.conf` лежит в репозитории и совпадает с боевым. Раньше он существовал только на
сервере (не был под git). Основной деплой делает `git reset --hard`, поэтому после слияния файл заменится
идентичным.

## Известные хвосты

- `robots.txt`, `sitemap.xml` и `llms.txt` на этом домене возвращают HTML главной со статусом 200 (из-за
  `try_files … /index.html`). Нужны настоящие файлы.
- Страница `/consent` основного сайта говорит про «сайт savagemovie.ru» и не называет поддомен `ai.`.
  Стоит попросить юриста добавить его.
